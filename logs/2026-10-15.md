## 三、今天学到的知识

### 函数（P1 最重要的一节）

- `def 函数名(参数):` + `return 结果`
- ⭐ **`print` 和 `return` 的区别**
  - `print` = 喊出来给屏幕看
  - `return` = 把结果交回去（**函数有返回值才能被继续使用**）
- **提前返回**（early return）：每个分支直接 `return`，不用先存变量
- 函数调用本身就是一个"值"，可以嵌进 f-string：`f"{describe_ph(ph)}"`
- `isinstance(x, (int, float))` 判断类型（认识即可）
- `raise` 主动抛错（认识即可）

### 文件读写（P1 最实用的一节）

- 模板：`with open(路径, "r", encoding="utf-8") as f:`
- `with` = 自动关闭文件，忘不掉
- 读法：`f.read()` / `f.readlines()` / ⭐ **`for line in f:`**
- 写法：`f.write(内容 + "\n")` —— **不会自动换行**
- 三种模式：`"r"` 读 / `"w"` 写（**会清空！**） / `"a"` 追加
- ⭐ **Windows 路径要加 `r`**：`r"D:\study\data.txt"`

### 三个"铁律"级的认知

| # | 认知 |
|:--:|---|
| 1 | ⭐ **Windows 上用 Python 读文件，永远写 `encoding="utf-8"`** —— 不写就是在赌，中文文件必输 |
| 2 | ⭐ **表头永远在第一行** —— CSV / Excel / 数据库导出，全都是第一行是列名 |
| 3 | ⭐ **相对路径**：`data/measurements.csv` 相对于「运行命令时所在的目录」 |

### 顺带自己学会的

- `+=` 累加赋值：`total += x` 等于 `total = total + x`
- `"-" * 32` 字符串乘法生成分隔线
- `readlines()` + `len()` 直接得到行数
- 列表切片 `lines[1:]` = 从第 2 个元素到结尾

## 五、⭐ 今天最大的收获：一个"绝招"

前面三次把文件放错位置，根本原因是**靠肉眼判断路径**。

**绝招**：在 VS Code 里**右键那个文件 → 「复制相对路径」**，直接粘进代码。

> 那是 VS Code 实际算出来的路径，**不可能错**。
