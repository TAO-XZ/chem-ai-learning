## 三、今天学到的知识

### 1. 数组 vs 列表（d15）

| | `list` | `ndarray` |
|---|---|---|
| 类型 | 什么都能混 | **必须同一类型** |
| 长度 | 能 `append` | **定长** |
| 形状 | 无 | **矩形，有 `shape`** |
| `* 2` | **复制两份** | **每个都乘 2** |

⭐ **三条限制换来的，就是向量化** —— 整块内存交给 C 批量算，快 10～100 倍。

### 2. `argsort` 给的是"编号"，不是"值"（d16）

```python
np.sort(d)      # 排好序的「值」
np.argsort(d)   # 排好序的「位置」  ← 找最近邻要的是这个
```

配切片：`np.argsort(d)[:3]` = 最近的 3 个的编号。

### 3. 二维数组：行是样本，列是特征（d17）

```python
X[0]        # 第 1 个样本的两个特征   → (2,)
X[:, 0]     # 所有样本的第 1 个特征   → (20,)
```

⭐ **`: ` 读作"所有"。** `X[:, 0]` = 所有行的第 0 列。

### 4. `axis` = 把第 k 维"消掉"（d17）

```
(20, 2) --axis=0--> (2,)     每个特征一个数
(20, 2) --axis=1--> (20,)    每个样本一个数
```

⭐ **判据：先想清楚结果的 shape 该是什么，再看 axis 填几。**

### 5. 广播：形状不同也能相减（d17）

```python
X - mu          # (20,2) 减 (2,) → numpy 自动把 mu 复制 20 份
```

**一行代码，40 个数全减完。** 这就是标准化的底层机制。

### 6. pandas 三步：读 → 验 → 取

```python
df = pd.read_csv("data/amino_acid_descriptors.csv")
df.shape      # (20, 8)     几行几列
df.columns    # 有哪些列     ← 列名从这里复制，别手打
df[['mw_da', 'hydrophobicity_kd']].values   # 双层中括号 = 选多列
```

## 五、⭐ 今天最大的收获：量纲问题被亲眼看到了

`d17` 顺带算出了两个特征的标准差：

| 特征 | 范围 | 标准差 |
|---|---|---|
| 分子量 | 89 ~ 204 | **30.08** |
| 疏水性 | −4.5 ~ 4.5 | **2.91** |

**差了 10 倍。**

这意味着：如果直接拿这两个数算距离，**分子量的贡献会死死压住疏水性** —— 疏水性怎么变，距离几乎不动。

> ### 为什么这件事对毕设致命
>
> JITL 叫"**局部**建模"，因为它只拿**最近邻**来建模型。
> **最近邻选错了，后面模型再精密也是错的。**
>
> 而"最近"怎么定义，取决于**有没有把量纲对齐**。
> 不标准化 → 算法选的是"分子量像"的样本，不是"化学性质像"的样本。

**明天 d18 要做的事，就是把这件事当场验证一遍**：同一个查询点，用原始数据选出的邻居，和标准化后选出的邻居 —— **只重合一个**。

## 六、下次从哪继续

**d18：欧氏距离 —— 多特征的 kNN**

```python
d = np.sqrt(((X - q)**2).sum(axis=1))    # axis=1 是生死线
```

要点：
- 公式就是勾股定理的推广
- 结果的 shape 必须是 `(20,)` —— 一个样本一个距离
- **查询点 `q` 也必须用同一套 `mu` / `sd` 变换**（最容易漏）
- 最后用 `argsort` 取前 3 —— 和 d16 完全一样

**验收**：

```
原始 最近3: ['Thr', 'Pro', 'Cys']
标准化 最近3: ['Asn', 'Asp', 'Pro']
```

**只有 Pro 两边都在** —— 这就是"量纲决定邻居是谁"的铁证。
