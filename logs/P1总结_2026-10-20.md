## 三、知识地图（7 块，全部走完）

```
1. 数据和变量    →  int / float / str / bool，类型转换、f-string
2. 控制流        →  if / elif / else，for，while，enumerate
3. 容器          →  list（有序、按位置）、dict（按键查找）
4. 函数          →  def / 参数 / return / 作用域 / 提前返回
5. 文件 IO       →  with open + encoding、readlines、pandas.read_excel
6. 异常处理      →  try / except / 具体错误类型 / continue
7. 模块          →  import、自己写 .py 被复用、if __name__ == '__main__'
```

> **这 7 块就是 Python 的语法地基。**
> 剩下的（类、装饰器、生成器、异步）都是在这上面盖楼，用到再学。

## 附：自测答案

1. **list** 有序、靠位置索引，适合"一组同类数据"（如所有浓度值）；**dict** 靠键查找，适合"名字 → 值"的映射（如元素名 → 摩尔质量、计数统计）。
2. **`print`** 把东西喊到屏幕上，函数返回 `None`，值留不下来；**`return`** 把值交回调用处，之后还能被赋值、参与运算、嵌进 f-string —— **有返回值才能被继续使用**。
3. Windows 中文环境默认用 **GBK** 解码，而现在的数据文件基本都是 **UTF-8**。不写 `encoding` 就是在赌，中文一定输。
4. `except ValueError` 只接住这一种错误，**其它错误照常崩**，bug 不会被藏起来；裸 `except:` 会把 `KeyboardInterrupt`、真正的 bug 一起吞掉，程序"看起来正常"但结果错了 —— **最难查的就是这种**。
5. **模块**就是一个 `.py` 文件，里面的函数/变量能被别的文件 `import` 复用。`if __name__ == '__main__':` 保证那段代码**只在直接运行本文件时执行**，被 import 时跳过 —— 这样同一个文件既能当"库"，又能当"测试脚本"。
6. **不会执行。** 只有 `python aa_utils.py` 直接运行时，`__name__` 才等于 `'__main__'`；被 `import` 时它等于模块名 `'aa_utils'`。
