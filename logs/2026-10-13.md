## 三、今天学到的知识

### Python

- 变量、数据类型：`str` / `int` / `float`
- **`input()` 永远返回字符串** → 要参与运算必须先转换
- `f"..."` 格式化输出；`{x:.2f}` 控制小数位
- `if / elif / else` 条件分支
- `for` + `range()` 循环（`range` 结尾**不包含**）
- **缩进就是语法**（4 个空格）
- **`=` 是赋值（动作），`==` 是比较（提问）**

### 终端 / 工具

- 命令：`cd` / `mkdir` / `move` / `python 文件名`
- Git 三层：**Ctrl+S 保存** → **`git commit`** → **`git push`**（互不自动）
- `git add .` 里的 `.` 前面**必须有空格**
- 用 <kbd>↑</kbd> 翻出历史命令，改一改重用

## 四、今天踩的 10 个坑（这份最值钱）

| # | 坑 | 教训 |
|:--:|---|---|
| 1 | conda 没加到 PATH，`conda` 命令找不到 | `conda init powershell` + **重启终端** |
| 2 | PowerShell 禁止运行脚本 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| 3 | VS Code「推荐的」解释器是 `D:\python\python.exe`（错的） | **"推荐"不等于"正确"**，要手动选 `chem` |
| 4 | 终端里打中文名字触发 `KeyboardInterrupt` | 输入法把 Ctrl+C 透传给了终端，重来即可 |
| 5 | 文件建错层级（**一天犯了两次**） | **看面包屑**：`python_basics > w02 > 文件` 才对 |
| 6 | 文件名拼成 `concentraion`，少一个 `t` | 计算机不会猜，差一个字母就是两个东西 |
| 7 | 按到 Insert 键，打字变成"覆盖"模式 | 状态栏会显示 `OVR`，点一下或再按一次 Insert |
| 8 | `git add.` 少一个空格 | Shell 靠**空格**分词；`'xxx' is not a git command` = 空格/拼写问题 |
| 9 | 命令漏了 `python`，直接敲文件路径 | PowerShell 会以为那是个命令 |
| 10 | 以为 Ctrl+S 会自动同步到 GitHub | **保存 ≠ 提交 ≠ 推送**，后两步必须手动 |
