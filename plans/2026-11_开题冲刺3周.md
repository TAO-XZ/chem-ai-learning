## 四、在线表单 4 个字段怎么写

### 字段 1 · 开题日期

**填实际开题那天**，建议 `2026-12-01`（和交报告同一天），或问张老师哪天算。

### 字段 2 · 本课题研究意义（≥200 字，建议 400–500 字）

**三段式，不要文献罗列：**

| 段 | 写什么 | 大概字数 |
|:--:|---|--:|
| ① 背景与痛点 | 酶固定化是多相催化的主流手段；**孔内微环境**（疏水性、电荷、氢键、空间限域）显著影响酶的构象与底物通道，但目前「一种载体只能调一种微环境」 | 150 |
| ② 现有方法的局限 | 实验上靠经验试错，**组合空间大、单次实验成本高**；纯数据驱动模型又受限于样本量，无法外推 | 150 |
| ③ 本课题的价值 | 把「选哪些样本建模」从**距离**升级到**局部数据几何**，并给出**预测可信度**；既能减少实验次数，又能在小样本下避免误用预测结果 | 150 |

**关键词要给到：** 孔内微环境、限域效应、JITL（即时学习）、局部数据几何、预测可靠性。

### 字段 3 · 研究内容（≥200 字，建议 400–500 字）

**三块，每块「做什么 + 得到什么」，不写读文献：**

```
① 局部数据几何的定量刻画
   对每个查询样本，计算其近邻集的距离分布与共线性（条件数），
   定义「铺得开」的量化指标，回答：邻居不仅要多近，还要多「不共线」。

② 基于几何约束的 JITL 样本选择
   在 kNN 选邻居的基础上加入几何筛选，比较「纯距离」「距离+几何」
   两种选择策略对局部模型精度的影响。

③ 预测可靠性评估
   用局部方差 / GP 后验方差给出每个预测的可信度，
   以「覆盖率」而非仅 RMSE 检验其有效性，给出「可不可信」的判据。
```

**⚠️ 审查项明确查「是否属于综述类论文」—— 这一栏必须全是「我做」，不能出现「某某研究了」。**

### 字段 4 · 技术路线、研究方法和研究进度

**三部分，缺一不可：**

**（1）技术路线 —— 一张流程图，文字 5 步：**

```
数据（酶微环境实验数据 18 条件 / 54 记录）
  → 特征（氨基酸描述符 + 酶描述符 + 负载量）
  → 局部建模（JITL = 局部加权最小二乘）
  → 样本选择（距离 + 局部几何）
  → 可靠性（不确定性 + 覆盖率检验）
  → 反馈：指导下一批实验点
```

**（2）研究方法 —— 写公式和指标：**

| 要素 | 写什么 |
|---|---|
| 局部模型 | 加权最小二乘 `min Σ wᵢ(yᵢ − xᵢᵀβ)²`，`wᵢ = exp(−dᵢ²/2h²)` |
| 样本选择 | 近邻 + 条件数阈值（或行列式 / 体积判据） |
| 超参 | 邻居数 k、带宽 h，用 LOO 选 |
| 评估 | RMSE、Spearman(预测, 实测)、**覆盖率**（误差落在 ±unc 内的比例） |
| 对照 | 全局线性回归 / 纯 kNN / 标准 JITL |

**（3）研究进度 —— 按学期排，落到月：**

| 时间 | 做什么 |
|---|---|
| 2026.11–12 | 文献调研 40 篇，完成开题；打通 JITL 原型 |
| 2027.01–03 | 几何指标与样本选择策略对比，中期答辩 |
| 2027.04–05 | 可靠性评估与覆盖率检验；撰写论文 |
| 2027.05–06 | 定稿、查重、答辩 |
