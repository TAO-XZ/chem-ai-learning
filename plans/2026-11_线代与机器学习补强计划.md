### 数学深度：三道闸门（「够用」的操作化定义）

| 级别 | 要求 | 怎么算过 |

| **L1 会算** | 能手算 2×2 矩阵 / 7 个点的小例子 | 手算结果 = 代码结果 |

### W1：向量、范数、内积 —— 「距离是一把尺子」

**日期**：11/09–11/15 ｜ **25 h**

**线代**（每条一句话，先能手写再往下）

| 概念 | 一句话 |
|---|---|
| 向量 | 一串有序的数；在特征空间里是一个**点**，从原点看是一支**箭头** |
| 内积 `xᵀy = Σxᵢyᵢ` | 衡量「两个方向有多一致」；`= ‖x‖‖y‖cosθ` |
| L2 范数 `‖x‖₂=√(xᵀx)` | 长度；两点相减再取范数 = 欧氏距离 |
| L1 / L∞ 范数 | 曼哈顿距离 / 最大分量差；**不同范数 = 不同形状的「等距球」** |
| 余弦相似度 | 只看方向不看长度；光谱/指纹比对常用 |
| 正交 | 内积 = 0；「互不干扰的两个方向」 |
| 标准化 | 左乘对角矩阵 `D⁻¹`：**换一把尺子，不改变数据本身** |

**ML 连接**

- **最近邻是谁，取决于尺子。** 你已经用 d18 证明过一次（原始 3 邻居 vs 标准化 3 邻居只重合 1 个）—— 这周把它做成可重复的实验。
- **标准化解决不了「特征没用」**（10-30 日志已得出）。这周给出定量解释：无用特征在距离里贡献的是**方差**，标准化只是把它的方差调到和别人一样大，等于**把噪音权重从 90% 调到 50%**。
- 维度灾难的定量版：d 维单位球体积占比 → 高维里「最近」和「最远」几乎一样远。

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m01_norms.py` | 手写 `l1/l2/linf`，与 `np.linalg.norm(x, ord=...)` 对照 | 三个数必须完全一致；`norm` 不写 `axis` 是对整个矩阵求范数（坑） |
| `m02_ruler.py` | 同一查询点，三种尺子（原始 / 标准化 / 只用疏水性）→ 三份邻居名单 + 重合率 | 查询点**也要用同一套 mu/sd**（d18 的坑） |
| `m03_cosine.py` | 20 个氨基酸 × 8 个描述符，算余弦相似度矩阵；找 Ser 最像的 3 个，和欧氏的结果比 | 余弦对「整体缩放」不敏感 → 描述符量纲差异大时反而更稳 |

**图**：`figures/m01_metric_neighbors.png` —— 三种尺子下，同一个查询点的邻居用连线画出来。

**验收**
1. 白板写出 `‖x‖₂ = √(xᵀx)`，并解释为什么开根号（否则不满足三角不等式）
2. 说出「标准化 = 换尺子」并举一个自己数据里的例子
3. 给出三份邻居的**重合率数字**（例如 2/3）

**资源**：3b1b 第 1、2、9 集（点积）｜MML（mml-book.github.io）2.1–2.4｜`np.linalg.norm` 文档

**坑**：`axis` 搞反；只对训练集标准化、忘了查询点；把「余弦」当成「相关系数」（差一个中心化）。

### W2：矩阵、秩、投影、最小二乘 —— 「从平均到解方程」

**日期**：11/16–11/22 ｜ **25 h**

**线代**

| 概念 | 一句话 |
|---|---|
| 矩阵 = 线性变换 | 每一列是「基向量被送到哪」；乘法 = 变换的复合 |
| 四种看法 | 行·列内积 / 列的线性组合 / 每个输出是一个内积 / 复合变换 |
| 秩 | 列空间维数 = 数据真正「张开」了几个方向 |
| 超定方程 | n > d，一般**无解** —— 所以要找「最接近的解」 |
| 投影 | 把 y 压到 X 的列空间上；残差 `y − Xβ` **垂直于**每一列 |
| 正规方程 | `XᵀX β = Xᵀy`，由「残差 ⊥ 每一列」直接推出（不需要导数） |
| 条件数 | `XᵀX` 最大/最小特征值之比；越大越病态，解越不稳 |
| R² | 几何上就是 `cos²θ`，θ 是 y 与列空间的夹角 |

**ML 连接**

- **线性回归不是「画一条直线」，是做投影。** 这一步想通，后面岭回归、PLS、JITL 全是同一个几何。
- **为什么 n=7、d=2 的 R² 会虚高**：自由度只有 `n−d−1 = 4`，R² 必然被抬高；这就是「调整 R²」存在的原因。
- **XᵀX 不可逆 = 有两列共线**。你现在只有 mw 和 hh 两列，还没炸；P4 上光谱（几百列）立刻炸 —— 那时靠 W3 的 SVD 和 W5 的 λI 救。

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m04_matmul.py` | 三重循环手写 `matmul`，与 `@` 对照；再用「列的线性组合」算一遍 | 三种视角算出同一个矩阵，才算真懂 |
| `m05_projection.py` | 2D：一堆点投影到一条直线上；画出残差，并用 `Xᵀr ≈ 0` 验证垂直 | 这是全计划最重要的一张图 |
| `m06_ols.py` | `β = solve(XᵀX, Xᵀy)`；与 `np.polyfit`、`sklearn.LinearRegression` 对照 | 用 `solve` 不用 `inv`；别忘了加一列 1 当截距 |

**图**：`figures/m02_projection.png` —— 点云、直线、垂下来的残差线段。

**验收**
1. 白板用「残差与每列正交」推出 `XᵀXβ = Xᵀy`（不查书）
2. 说清 `XᵀX` 不可逆意味着什么，并构造一个共线的反例让它报错
3. 三方系数差 < 1e-10；报出 `cond(XᵀX)` 的数值

**资源**：3b1b 第 3、4、7 集｜18.06 L1–L4（选看）｜MML 2.5–2.7

**坑**：漏截距列；用 `inv` 导致数值误差；`X` 没中心化就把 β₀ 解释成「基线」。

### W3：特征值、SVD、PCA —— 「找出数据躺着的方向」

**日期**：11/23–11/29 ｜ **25 h**

**线代**

| 概念 | 一句话 |
|---|---|
| 特征值/特征向量 | `Av = λv`：这个方向**只被拉长，不被转歪** |
| 对称矩阵 | 一定可以正交对角化：`A = QΛQᵀ`，特征向量互相垂直（协方差矩阵就是这种） |
| 协方差矩阵 | 对角线是各方差，非对角是「一起变的程度」；描述点云的**形状** |
| SVD | `A = UΣVᵀ`：任何矩阵 = 旋转 · 拉伸 · 旋转；奇异值 = 拉伸倍数 |
| 低秩近似 | 只留最大的 k 个奇异值 = 在最小平方误差意义下的最优压缩 |
| 解释方差比 | `σᵢ² / Σσⱼ²`；前 k 个加起来 = 保住了多少信息 |

**ML 连接**

- **PCA = 中心化后做 SVD**（或对协方差矩阵做特征分解，两者数学等价）。不是新算法，是 W3 的直接推论。
- **PCA 的三种用途**：可视化（20 个氨基酸画到 2D）、去噪（丢掉小奇异值）、**异常检测**（在残差空间里看 SPE —— P6 的 MSPC 就是它）。
- **PLS 一句话预告**：同时降维 X 和 y，让降维方向「朝着能预测 y 的方向」—— P4 的主角。PCA 是无监督版，PLS 是有监督版。

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m07_eigen.py` | 2×2 解析解手算 + `np.linalg.eig` 对照；验证 `Av − λv ≈ 0`；画特征向量方向 | 特征向量符号任意（±），比较时取绝对值 |
| `m08_pca.py` | 手写 PCA：中心化 → SVD → 取前 k → 反投影，**≤ 20 行**；与 `sklearn.PCA` 对照 | 比较 `explained_variance_ratio_`，不是比较 U 的符号 |
| `m09_pca_aa.py` | 20 个氨基酸 × 8 个描述符做 PCA，画 PC1–PC2 载荷图 + 得分图，标出已测的 7 种 | 这张图能直接进报告和开题 |

**图**：`figures/m03_pca_aa.png`（双面板：左得分、右载荷）

**验收**
1. 手算一个 2×2 对称矩阵的特征值（纸笔，30 秒内）
2. 解释「为什么必须中心化」：不中心化，第一主成分指向**均值方向**，不是方差最大方向
3. 报出前 2 个 PC 的解释方差百分比
4. 说清 PCA 和 SVD 的关系（一句话：PCA 的得分 = `UΣ`，载荷 = `V`）

**资源**：3b1b 第 13、14 集｜18.06 L21–22、L29–30｜MML 4.1–4.3｜StatQuest「PCA」两集

**坑**：只中心化 vs 标准化，结果差很多（描述符量纲差 10 倍，必须先标准化）；把 PC1 当成某个原始特征解释。

|---|---|
| 期望、方差 | 长期平均 / 围绕平均的散布；样本方差是**估计**，本身也有波动 |
| 标准误 | `sd/√n`；n=3 时它大到能让「31% 提升」变成 p=0.144 |
| 协方差矩阵 | W3 的形状描述，这里补定义：`E[(x−μ)(x−μ)ᵀ]` |
| 偏差-方差分解 | `E[(ŷ−y)²] = bias² + variance + σ²`；模型复杂度换的是这三项的比例 |

**ML**

| 概念 | 一句话 |
|---|---|
| 训练/验证/测试 | 三个集子干三件事：拟合、选模型、报成绩。**测试集只能用一次** |
| LOO | n 很小的时候唯一诚实的划分；但它训练的模型「几乎一样」，方差大 |
| 嵌套 CV | 外层评估、内层选超参；**不嵌套就会把「挑最好」算成「本来就好」** |
| 选择偏差 | 你的 21 种切法里挑最小 → 报出来的均值系统性偏低 |
| 学习曲线 | 训练/验证误差 vs n；两条线合拢 = 数据够了，有缝隙 = 数据不够 |

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m10_bias_variance.py` | 已知真值 `f(x)` 的模拟：重复采样 B=200 次，把固定点的 MSE 拆成 bias² + var + σ²，画三条曲线 vs 复杂度 | **这是唯一能「看见」理论的地方**，必须画出来 |
| `m11_nested_cv.py` | 复现 `_tmp_d28` 的 21 种切法；对比「先挑 k 再报分」vs「嵌套 CV」 | 输出两个数，差值就是**乐观偏差**（百分比） |
| `m12_learning_curve.py` | n=3…7 的学习曲线（每个 n 重复多次留出） | 回答「再加数据能救吗」 |

**图**：`figures/m04_bias_variance.png`、`figures/m05_selection_bias.png`

**验收**
1. 报出你自己的**挑选偏差数字**（例：乐观 12%），并解释为什么会乐观
2. 说清「验证集用过一次就不能再用」的原因
3. 用自己的数据说：「n=7 时 RMSE 的 95% 区间大概是 ±__」→ 以后不许再为 0.001 的改进兴奋

**资源**：李宏毅 ML 2023 第 1–4 讲｜ISLR 2.2、5.1–5.3｜StatQuest「Bias-Variance」「Cross Validation」

**坑**：标准化放在 LOO 循环外（**数据泄漏**，最常见）；把训练误差当性能；在 21 种切法里挑最好再报平均。

### W5：正则化、加权最小二乘、JITL —— 「把工程问题写成矩阵」

**日期**：12/07–12/13 ｜ **25 h** ｜ ⭐ **本周直接产出开题的方法章节**

**线代**

| 概念 | 一句话 |
|---|---|
| 条件数（复习） | `XᵀX` 的特征值跨度；加 `λI` 就是把所有特征值抬到 `λᵢ+λ`，**病态被治好** |
| 约束优化 | 在「β 不能太大」的约束下最小化残差；λ 是约束强度的价格 |
| 岭闭式解 | `β = (XᵀX + λI)⁻¹Xᵀy`；λ→∞ 时 β→0，λ→0 时退回 OLS |
| SVD 视角 | 岭回归 = 把每个奇异值方向的系数乘 `σᵢ²/(σᵢ²+λ)` —— **小的方向被压得最狠** |
| L1 vs L2 | L2 是圆、L1 是菱形；菱形有尖角 → 最优解常落在坐标轴上 → **稀疏** |

**ML**

| 概念 | 一句话 |
|---|---|
| p ≫ n | 特征比样本多时，OLS 有无穷多解；必须靠正则化挑一个 |
| 正则化路径 | λ 从大到小，画出每个系数怎么长大 —— 一眼看出「谁先进模型」 |
| WLS | 每个样本一个权重 `wᵢ`：`min Σwᵢ(yᵢ−xᵢᵀβ)²`，解是 `(XᵀWX)⁻¹XᵀWy` |
| 局部加权（LWR） | 对**每个查询点**重新解一次 WLS，权重 = 距离核 `exp(−d²/2h²)` |
| JITL | 就是「局部 + 在线」的 WLS/PLS：**不是新算法，是 W5 的直接应用** |

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m13_ridge.py` | 手写闭式解；λ 扫描画系数路径；LOO 选 λ | 惩罚项**不罚截距**；X 先标准化，否则 λ 没有可比性 |
| `m14_jitl.py` | 手写 WLS + 高斯核；在 Cyt c 7 点上对比：全局线性 / kNN / 局部线性（扫带宽 h） | **这就是毕设方法的最小原型**，parity plot 要能放进开题 |
| `m15_cond.py` | 同一张图上画 `cond(XᵀX)` vs λ，和 RMSE vs λ | 证明「正则化 = 治共线」 |

**图**：`figures/m06_ridge_path.png`、`figures/m07_jitl_bandwidth.png`

**验收**
1. 手写 `β_ridge`，并解释 λ→∞ 时 β→0、λ→0 时退回 OLS
2. 画出 λ–RMSE 曲线并选出 λ（用 LOO，不用训练误差）
3. 一句话说清 JITL 和 kNN 的区别：**kNN 是局部平均，JITL 是局部建模**
4. 报出「局部线性 vs kNN」在你的数据上的 RMSE 对比（谁赢都行，要能解释）

**资源**：ISLR 6.2｜ESL 3.4（选看）｜StatQuest「Ridge/Lasso」｜**杨鑫 2018 + 再找 2 篇 JITL**，把论文里的加权公式抄下来对照 `m14`

**坑**：罚了截距；没标准化就调 λ；内层选 λ 用了外层数据（又是泄漏）；带宽 h 太小 → 每个点自己拟合自己。

### W6：核、GP、贝叶斯优化 —— 「把不确定性变成决策」

**日期**：12/14–12/20 ｜ **25 h**

**线代**

| 概念 | 一句话 |
|---|---|
| 核函数 | 把内积换成「相似度」`k(x,x')`，不用显式升维 |
| Gram 矩阵 | `Kᵢⱼ = k(xᵢ,xⱼ)`，n×n；GP 的全部信息都在这张表里 |
| 正定 | 对任意向量 `vᵀKv > 0`；RBF 核一定正定 → 才能做 Cholesky |
| Cholesky | `K = LLᵀ`，矩阵的「平方根」；解方程比 `inv` 快一倍、稳一个量级 |

**ML**

| 概念 | 一句话 |
|---|---|
| GP 回归 | 给每个点一个**分布**而不是一个数；观测后收窄，没观测的地方仍然宽 |
| 预测均值/方差 | 均值 = 加权内插，方差 = 「这里有没有数据」的度量 |
| 采集函数 EI | `E[max(f−f*, 0)]`：既想高（利用），又想去没去过的地方（探索） |
| 贝叶斯优化 | 代理模型（GP）+ 采集函数 + 真实实验，循环；**专为「一次实验很贵」设计** |

**为什么这周对你特别重要**：你报告 §五 写「补测时优先选**离现有数据最远**的氨基酸」—— 那不是拍脑袋，那就是 **EI 的探索项**。W6 之后，这条建议会变成一个有公式、能算下一个该测谁的方案。

**代码**

| 文件 | 干什么 | 关键点 |
|---|---|---|
| `m16_gp.py` | 手写 1D GP：RBF 核 → K + σ²I → Cholesky → 后验均值/方差；画 3 个观测点、5 个观测点的带子 | 必须加噪声项，否则 K 奇异；与 `sklearn.GaussianProcessRegressor` 对照 |
| `m17_bo.py` | 1D 目标（如 `−(x−2)² + sin(5x)`），EI 采集，跑 10 轮 vs 随机 10 轮 | 画「当前最优 vs 轮数」两条线 |

**图**：`figures/m08_gp.png`（先验/后验/方差带）、`figures/m09_bo.png`

**验收**
1. 指着 K 矩阵说清每一格是什么、为什么对角线要加 σ²
2. 说清 Cholesky 比 `inv` 好在哪（数值稳定 + 快）
3. 图上指出「观测点附近方差→0、远处→先验方差」
4. 用轮数说话：BO 几轮达到随机搜索的水平

**资源**：Rasmussen & Williams《GP for ML》ch.2（免费 PDF）｜Distill「Visual Exploration of Gaussian Processes」｜Frazier 2018《A Tutorial on Bayesian Optimization》前 10 页

**坑**：忘加 σ²I → Cholesky 报「矩阵不正定」；EI 公式符号错；目标没做 log 变换（你的 kcat/Km 跨 3 个数量级，**必须取 log**）。
